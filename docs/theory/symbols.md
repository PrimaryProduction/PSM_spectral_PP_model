# Symbols and units

| Symbol | Code name | Meaning | Unit |
|---|---|---|---|
| $\lambda$ | `wavelengths` | wavelength | nm |
| $\Delta\lambda$ | `d_lambda` | width of a wavelength band | nm |
| $z$ | `depths` | depth (positive downward) | m |
| $t$ | `dtm` | local solar time | h |
| $\phi$ | `lat` | latitude | degrees N |
| $\delta$ | `daylight.delta` | solar declination | rad |
| $\theta_s$ | `zenith_deg`, `zenith_rad` | solar zenith angle in air | deg / rad |
| $\theta_w$ | `zenw` | refracted (in-water) angle of the direct beam | rad |
| $D$ | `daylength` | day length | h |
| PAR | `par` | daily photosynthetically available radiation above the surface | einstein m⁻² d⁻¹ |
| $I_m$ | `iom` | noon PAR irradiance | einstein m⁻² h⁻¹ |
| $B$, $C$ | `chl`, `chl_profile` | chlorophyll-a concentration | mg m⁻³ |
| $z_m$, $\sigma$, $\rho$ | `z_m`, `sigma`, `rho` | DCM depth, width, relative height | m, m, – |
| $C_p, C_n, C_m$ | `pico_chl`, `nano_chl`, `micro_chl` | chlorophyll in size classes | mg m⁻³ |
| $a^*_i$ | `PICO`, `NANO`, `MICRO` | chlorophyll-specific absorption | m² (mg Chl)⁻¹ |
| $a_{ph}$ | `ac` | phytoplankton absorption | m⁻¹ |
| $a_w$ | `aw` | pure-water absorption | m⁻¹ |
| $a_y$ | `ay` | CDOM absorption (`ay` is normalised to 440 nm) | m⁻¹ |
| $Y$ | `yellow_substance` | $a_y(440)/a_{ph}(440)$ | – |
| $a$ | `atot` | total absorption | m⁻¹ |
| $b_w$ | `bw` | pure-seawater scattering | m⁻¹ |
| $b_{br}$ | `bbr` | Raman backscattering | m⁻¹ |
| $b_p$ | `bc` | particle scattering | m⁻¹ |
| $\tilde b_b$ | `bbtilda` | particle backscattering ratio | – |
| $b_b$ | `bb` | total backscattering | m⁻¹ |
| $\mu_d$ | `mu_d` | mean cosine of downwelling light | – |
| $K_d$ | `K` | diffuse attenuation coefficient | m⁻¹ |
| $E_\text{dir}, E_\text{dif}$ | `direct`, `diffuse` | direct and diffuse irradiance | W m⁻² µm⁻¹ (`irradiance`), einstein m⁻² h⁻¹ nm⁻¹ (`surface_light`) |
| $E_d$ | `Iz` | downwelling spectral irradiance | einstein m⁻² h⁻¹ nm⁻¹ |
| $M$ | `airmass` | relative optical air mass | – |
| $T_r, T_a, T_w, T_o, T_u$ | `tr`, `ta`, `tw`, `to`, `tu` | atmospheric transmittances | – |
| $\rho_s$ | `air_albedo`, `ro_S` | sky albedo | – |
| $P^B_m$ | `Pb_m` | assimilation number | mg C (mg Chl)⁻¹ h⁻¹ |
| $\alpha^B$ | `Al_b` | initial slope of the P–I curve | mg C (mg Chl)⁻¹ h⁻¹ (W m⁻²)⁻¹ |
| $P$ | `PP` | primary production | mg C m⁻³ h⁻¹ |

1 einstein = 1 mol of photons.
