# Getting started

## Repository layout

The model is a set of small, flat Python modules (not a package). Import them
from the repository root, or install the project so they are on the path.

| File | Purpose |
|---|---|
| `config.py` | Default wavelength grid (400–700 nm, 5 nm), depth grid (0–250 m, 0.5 m) and constants |
| `chlorophyll.py` | Shifted-Gaussian chlorophyll profile from surface chlorophyll |
| `size_fraction.py` | Pico/nano/micro partition of chlorophyll (Brewin et al. 2010) |
| `absorption.py` | Phytoplankton absorption from size-specific spectra |
| `scatter.py` | Absorption and scattering by pure water, Raman scattering, CDOM shape |
| `daylight.py` | Solar declination, zenith angle, sunrise, day length |
| `irradiance.py` | Clear-sky spectral direct and diffuse irradiance (Bird 1984) |
| `surface_light.py` | Below-surface spectral irradiance at an instant, scaled to satellite PAR |
| `light_profile.py` | Attenuation coefficients and the underwater light field |
| `light_field.ipynb` | Notebook that walks through the model |
| `mkdocs.yml`, `docs/` | This documentation |

## Installing with pixi (recommended)

The project ships a [pixi](https://pixi.sh) configuration in `pyproject.toml`
that pins all dependencies from conda-forge.

```bash
git clone https://github.com/PrimaryProduction/PSM_spectral_PP_model.git
cd PSM_spectral_PP_model
pixi install            # creates .pixi/ with the default environment
pixi run notebook       # opens light_field.ipynb in JupyterLab
```

Run any script with the environment active:

```bash
pixi run python -c "import daylight; print(daylight.daylength('2020-06-21', 60))"
```

## Installing with pip or conda

The model needs only **numpy**, **scipy** and **pandas**; the notebook also
uses **matplotlib** and **jupyter**.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -e .        # optional: makes the modules importable anywhere
```

With conda/mamba:

```bash
mamba create -n psm -c conda-forge python=3.12 numpy scipy pandas matplotlib jupyterlab
mamba activate psm
```

## Running on Binder or WEkEO

The notebook is self-contained and runs in any hosted Jupyter service:

- **Binder** – [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/PrimaryProduction/PSM_spectral_PP_model/HEAD?labpath=light_field.ipynb)
  builds an environment from `requirements.txt`. It is quick to try but slow to
  start, and sessions are lost when the tab closes.
- **WEkEO JupyterHub** – a free, persistent JupyterLab environment from the EU
  Copernicus programme. Create an account at
  <https://wekeo.copernicus.eu/register>, start a server from
  <https://wekeo.copernicus.eu/my-wekeo>, open a terminal and run

  ```bash
  git clone https://github.com/PrimaryProduction/PSM_spectral_PP_model.git
  cd PSM_spectral_PP_model
  pip install --user -r requirements.txt
  ```

  then open `light_field.ipynb`. The
  [Non-spectral practical README](https://github.com/PrimaryProduction/Non_spectral_PP_model#running-the-practical-on-wekeo)
  describes these steps in more detail.

## Building this documentation

The site is built with [MkDocs](https://www.mkdocs.org/),
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) and
[mkdocstrings](https://mkdocstrings.github.io/), which renders the numpydoc
docstrings in the source into the [API reference](api/index.md).

```bash
pixi run -e docs docs-serve     # live preview at http://127.0.0.1:8000
pixi run -e docs docs-build     # static site in ./site (open site/index.html)
```

Without pixi:

```bash
pip install mkdocs mkdocs-material "mkdocstrings[python]"
mkdocs serve
```

The figures in the documentation are generated by the model itself:

```bash
pixi run -e docs python docs/scripts/make_figures.py
```

### Publishing on GitHub Pages

`.github/workflows/docs.yml` runs the docstring examples, builds the site and
deploys it to GitHub Pages on every push to `main`. Enable it once under
**Settings → Pages → Build and deployment → Source: GitHub Actions**. The site
is then served at
<https://primaryproduction.github.io/PSM_spectral_PP_model/>.

Alternatively, deploy by hand to a `gh-pages` branch:

```bash
pixi run -e docs mkdocs gh-deploy
```

## Testing

All docstrings contain runnable examples that double as tests:

```bash
pixi run python -m doctest *.py
```
